# DuckBot Module Organization

This directory contains the organized DuckBot modules with clear separation of concerns.

## Core Modules (root level)
- `cost_management.py` - Cost tracking and analytics
- `charm_manager.py` - Terminal UI and styling
- `webui_manager.py` - Web interface management
- `ai_router_manager.py` - AI model routing
- `consolidation_mapping.py` - Backward compatibility

## Core Systems (`core/`)
Fundamental system components and utilities

## Integrations (`integrations/`)
External service integrations and third-party connections

## Platforms (`platforms/`)
Cross-platform support and environment-specific functionality

## Services (`services/`)
Background services and system management

## Agents (`agents/`)
Multi-agent systems and AI orchestration

## UI (`ui/`)
User interface components and presentation layer

## Tools (`tools/`)
Development tools and utilities

## Structure Benefits:
- ✅ Clear separation of concerns
- ✅ Easier navigation and maintenance
- ✅ Logical grouping by functionality
- ✅ Better scalability for future additions
- ✅ Reduced cognitive load for developers
