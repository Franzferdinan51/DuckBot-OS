## 🚀 Quick Start

1. **Launch DuckBot**: Double-click `launcher/START_ENHANCED_DUCKBOT.bat`
2. **Choose your experience**:
   - Option 1: Complete Ultimate Enhanced Mode - All features activated
   - Option 2: Enhanced WebUI - Original style with dark theme and multi-agent chat
   - Option U: UI-TARS Desktop Automation - ByteDance-powered GUI automation
   - Option D: DuckBot Chat Assistant - Interactive AI chat interface
   - And many more options...

3. **Copy the token URL** from terminal output
4. **Paste in browser** → Instant access to the AI-powered future!

## 🛠️ System Requirements

### Minimum Requirements
- **Windows 10/11** (WSL2 for enhanced features)
- **Python 3.8+** (3.10+ recommended)
- **4GB RAM** minimum (8GB+ recommended)
- **2GB free disk space**
- **Go 1.20+** (auto-installed by setup script)

### Recommended for Full Experience
- **16GB RAM** for optimal multi-agent performance
- **NVIDIA GPU** for AI acceleration (optional)
- **Node.js 16+** for React WebUI components
- **WSL2** for Linux integration and enhanced development
- **Git** for development and workflow features
